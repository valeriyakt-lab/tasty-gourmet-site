# Хранение ключей

- Реальные ключи лежат в `.env` (он в `.gitignore`, в репозиторий не попадает).
- Список нужных переменных — в `.env.example`.
- Использование: `./scripts/env.sh <команда>` подставит ключи из `.env` в окружение команды.
- В продакшене задавайте те же переменные в Netlify (Site settings → Environment variables).
- Ключи нельзя вшивать в HTML-файл: всё, что в нём, видно любому посетителю.
  Секретные вызовы делайте на сервере (Netlify Functions), а в браузер отдавайте только публичные ключи.
