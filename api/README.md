# Серверные функции (Vercel)

| Файл | Что делает |
|---|---|
| `send-order.js` | Передаёт заказ в iiko. При сбое помечает заказ «не принят» и шлёт сообщение в Telegram. Вызывается сайтом после оформления и кнопкой «Отправить в iiko» в админке. |
| `new-request.js` | После заявки на регистрацию присылает в Telegram сообщение с кнопками «Одобрить» / «Отклонить». |
| `telegram.js` | Принимает нажатия кнопок из Telegram (webhook). Одобрение создаёт клиента и присылает его личную ссылку. |
| `check.js` | Проверка связи с Telegram и iiko из «Настройки» в админке (только администратор). |

## Переменные окружения (Vercel → Settings → Environment Variables)

| Переменная | Откуда взять |
|---|---|
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase → Project Settings → API → `service_role` (секретный, никому не показывать) |
| `TELEGRAM_BOT_TOKEN` | @BotFather → создать бота |
| `TELEGRAM_CHAT_ID` | id чата или группы, куда писать (бота нужно добавить в чат) |
| `TELEGRAM_SITE_LABEL` | (необязательно) подпись в начале каждого уведомления, чтобы было видно, какой сайт написал. По умолчанию «Новый сайт Tasty Gourmet» |
| `TELEGRAM_APPROVER_IDS` | (необязательно) id людей через запятую, кому разрешено нажимать «Одобрить/Отклонить». Пусто = любой участник чата |
| `IIKO_API_LOGIN` | iikoWeb → API (apiLogin) |
| `IIKO_APP_ID`, `IIKO_CLIENT_SECRET` | как в рабочем сценарии n8n (узел «Заказ в iiko»: `appId` и `clientSecret` в запросе токена). Если не заданы, используется стандартная авторизация только по apiLogin |
| `IIKO_ORGANIZATION_ID`, `IIKO_TERMINAL_GROUP_ID` | (необязательно) если в iiko единственная организация и касса, определяются автоматически. Иначе «Настройки» → «Проверить iiko» покажет значения |
| `IIKO_PAYMENT_NAME` | (необязательно) тип оплаты в iiko, по умолчанию «Банковские карты»; пустое значение = без оплаты |
| `IIKO_CITY` | (необязательно) город в адресе доставки, по умолчанию «Алматы» |

Пока `IIKO_API_LOGIN` не задан, заказы остаются со статусом «Новая» и обрабатываются вручную.
После изменения переменных нужен Redeploy.

## Кнопки в Telegram

Кнопки работают через webhook, а у одного бота он может быть только один. Поэтому для нового сайта нужен **отдельный бот** (@BotFather → /newbot), добавленный в тот же чат.
После добавления `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` нажмите в админке «Настройки» → «Подключить кнопки Telegram».
Если у бота уже стоит чужой webhook (например, n8n), подключение откажется, чтобы не сломать старый сайт.
